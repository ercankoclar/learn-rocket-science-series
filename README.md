# 🚀 Learn Rocket Science

This repository contains the technical files, designs, calculations, and documentation developed as part of the **Learn Rocket Science** video series.

The project focuses on learning and applying the fundamentals of rocket science through engineering, simulation, electronics, mechanical design, and experimentation.


## 🎥 Video Series

This repository is developed alongside the **Learn Rocket Science** video series.

The videos explain the concepts and development process, while this repository provides the technical files and supporting materials used throughout the series.
